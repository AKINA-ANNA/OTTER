Test clock

Simulated "today" — test overdue notices without waiting for real time

Set a simulated date and both the student dashboard and the teacher console treat it as "today". The overdue engine and due-date notices run against this simulated date instead of the real calendar. While it is set the clock is held still, so countdowns on both dashboards stop moving. Use Disable test clock to hand the real date and time straight back to both dashboards.
